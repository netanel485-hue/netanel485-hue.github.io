# English Boost: תכנית עבודה

עודכן: 18/11/2026. הערכה: `english-boost/` (חיזוק דקדוק באנגלית למבוגרים דוברי עברית).

## הקונספט: "מחברת עם עט אדום"
מחברת אישית, שבה מורה עובר עם עט אדום, וכל תיקון הופך עם הזמן לדיו קבוע. רציני ונעים, בלי לבבות ובלי לחץ רצף.

1. **צבע = מצב הטעות.** אדום (פתוחה) → כתום (בתיקון) → ירוק (הוכחה במשפט חדש) → כחול-דיו (שולט). אותו מחזור בכל המסכים.
2. **המשוב מראה מה השתנה.** התשובה שלך עם מחיקה באדום והוספה בירוק, מילה מול מילה.
3. **אנגלית בגופן סריף, עברית בגופן פשוט.**
4. **"היום" הוא עמוד במחברת:** תאריך, עד 3 שורות, ולכל שורה הסיבה. ההתקדמות נמדדת בטעויות שנסגרו.

טכנית: שכבת עיצוב נפרדת עם id (`eb-notebook-css`), אסימוני צבע למצבים ולמצב כהה, ורכיבים משותפים.
